# Trabalho de Conclusão de Curso - Beatriz de Quadros Schmitt
Este repositório representa o Trabalho de Conclusão de Curso de Beatriz de Quadros Schmitt, realizado no curso de Ciências da Computação pela Universidade Federal de Santa Catarina, em 2026.

## Execução local
Para executar o projeto localmente:
1. Caso ainda não tenha, instale o [Node.js](https://nodejs.org/en/download)
2. Clone o repositório:<br>
`git clone <URL_DO_REPOSITORIO>`
4. Acesse a pasta do projeto:<br>
  `cd projeto-tcc`
6. Instale as dependências:<br>
`npm install`
8. Execute o projeto:<br>
`npm run dev`
9. Acesse o endereço informado no terminal.
